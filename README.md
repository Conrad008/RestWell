## restWell  | user dashboard

restwell is an online platform which helps people moniter their sleep schedule by reminders and daily motivational quotes.the official site is built by htmll css and javascript which helps to load daily mesages for users

## project overview
restwell dashboard is a clean responsive application where users add their name age and this data is processed and it is then personalised for the users.

## features
**Data Persistence (localStorage):** The app saves the user's name (userName) and age (userAge) inside the browser's memory. This means the dashboard stays visible even if you refresh the page.

**Custom Stylesheet (style.css):** Built entirely with standard CSS layout rules. It features a diagonal background gradient, rounded content cards, clean input spacing, and responsive padding.

**Conditional Message Box:** Checks the user's age using an if...else statement. If the user is 18 or older, they are able to access adult content an if not tthey are barred from so.
